🚗 AutoVerse

Catálogo interativo de carros desenvolvido para fins de estudo em Fullstack.

🧠 Objetivo

Permitir que usuários explorem marcas, modelos e especificações técnicas de carros.

🛠️ Tecnologias
Frontend: Next.js + TypeScript + Tailwind
Backend: Node.js + Express
Banco de dados: PostgreSQL
ORM: Prisma
🚀 Funcionalidades (MVP)
Listar marcas
Listar modelos por marca
Visualizar detalhes do carro
Exibir ficha técnica
Exibir história do modelo
